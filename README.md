# 网络空间创新创业实践

第 26 组课程实验仓库

小组成员：安泊仰、李汶峰、赵孙梦元、孙名璋

仓库共包含 7 个实验。每个 Task 的 README 用于说明任务内容、主要文件和运行方法，完整实验过程见对应目录中的报告。

## 实验内容与分工

### [Task 1：Bitcoin 测试网络交易与区块解析](./Task%201/)

在 Bitcoin Testnet4 上构造并广播交易，并从原始字节解析交易和完整区块。

- 安泊仰：配置测试网钱包，构造并广播交易
- 李汶峰：实现交易、区块解析和逐字节字段映射
- 赵孙梦元：完成密码学、Script、Merkle 根和 PoW 检查
- 孙名璋：编写测试、绘制结果图并整理报告

### [Task 2：libsecp256k1 安全与性能分析](./Task%202/)

分析 Bitcoin Core 中 libsecp256k1 的常数时间修复、域运算实现调整和固定基点乘法优化。

- 安泊仰：调研相关 PR，分析常数时间修复
- 李汶峰：搭建编译环境，复现不同版本并运行正确性测试
- 赵孙梦元：整理椭圆曲线原理和源码实现差异
- 孙名璋：采集汇编与性能数据，绘图并整理报告

### [Task 3：对称密码算法的软件实现与优化](./Task%203/)

实现 AES、SM4、GIFT-128、TWINE-128 以及 CTR、GCM、XTS 模式，并比较不同软件优化方法。

- 安泊仰：实现 CTR、GCM、XTS 模式并检查边界条件
- 李汶峰：实现 AES、SM4 及 T-table、AES-NI 优化
- 赵孙梦元：实现 GIFT-128、TWINE-128 和 SIMD Shuffle 优化
- 孙名璋：完成正确性测试、性能测试和结果整理

### [Task 4：SM3 软件实现与架构优化](./Task%204/)

实现 SM3 的纯 C、AVX2、AVX-512 和 ARM64 NEON 路径，并测试运行时选择与四路多缓冲。

- 安泊仰：整理算法流程，实现参考版本和标准向量测试
- 李汶峰：实现 AVX2、AVX-512 路径和运行时选择
- 赵孙梦元：实现 ARM64 NEON 路径，检查跨平台构建
- 孙名璋：实现多缓冲，完成随机测试和性能测试

### [Task 5：CKKS 密文卷积](./Task%205/)

使用 TenSEAL 对 `4×4` 输入执行 `3×3` 密文卷积，并将解密结果与明文卷积进行比较。

- 安泊仰：选择 CKKS 参数，设计客户端与服务器流程
- 李汶峰：实现 im2col 编码、密文卷积和上下文序列化
- 赵孙梦元：完成明文对照、误差测试和结果绘图
- 孙名璋：配置实验环境，统计运行数据并整理报告

### [Task 6：CKKS 旋转次数与稀疏优化](./Task%206/)

分析密文卷积中的旋转—累加过程，并利用卷积核中的零权重减少打包槽位和旋转次数。

- 安泊仰：梳理 TenSEAL 卷积流程和实验方案
- 李汶峰：建立旋转次数模型，完成下界推导和源码分析
- 赵孙梦元：实现稀疏卷积方案并编写自动化测试
- 孙名璋：运行对照实验，统计误差与耗时并整理报告

### [Task 7：DeepSeek 模型安全测评](./Task%207/)

使用 garak 测试 DeepSeek 在提示注入、越狱、毒性内容、敏感信息泄露和恶意代码生成等场景下的表现。

- 安泊仰：配置 garak、LiteLLM 和模型接口，完成提示注入测试
- 李汶峰：完成 DAN 越狱和毒性内容测试
- 赵孙梦元：完成 API Key 泄露和利用型攻击测试
- 孙名璋：完成恶意代码生成测试，汇总数据并撰写报告
