| 项目 | 内容 |

## 二、项目概述

本仓库为第 26 组网络空间创新创业实践课程的实验成果，共包含 7 项实验。实验内容涵盖区块链安全、椭圆曲线密码库分析、对称密码与哈希算法优化、全同态加密以及大语言模型安全测评。

各实验目录中包含相应的源代码、测试程序、实验数据、运行结果和实验报告等材料，具体复现方法与技术细节见各实验目录内的说明文档。

## 三、实验内容及成员分工

### 1. [Bitcoin 测试网络交易、逐位解析与完整区块审计](./Task%201/)

**实验简介：** 在 Bitcoin Testnet4 上构造并广播交易，自主完成交易及完整区块的反序列化和逐字节、逐位字段映射，并验证 txid、wtxid、Merkle 根、工作量证明以及 P2WPKH、P2WSH 脚本的执行结果。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 安泊仰 | 测试网钱包配置、交易构造与广播、链上交易证据整理 |
| 李汶峰 | Bitcoin 协议解析、密码学与 Script 验证模块开发、自动化测试 |
| 赵孙梦元 | 完整区块审计、实验结果可视化、实验报告整理 |

### 2. [libsecp256k1 常数时间修复与性能改进分析](./Task%202/)

**实验简介：** 围绕 Bitcoin Core 的 libsecp256k1，分析常数时间编译鲁棒性修复、旧 x86_64 域运算汇编移除及 signed-digit multi-comb 固定基点乘法优化，并结合汇编检查、源码差异和微基准测试评估其安全性与性能变化。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 安泊仰 | 相关 PR 调研、调用路径梳理、常数时间修复的源码与安全性分析 |
| 孙名璋 | 汇编证据采集、性能基准测试、数据制图与实验报告整合 |

### 3. [对称密码算法的软件实现与优化](./Task%203/)

**实验简介：** 实现 AES、SM4、GIFT-128 和 TWINE-128，对比标量、循环展开、T-table、SIMD Shuffle 与 AES-NI 等优化路径；同时实现并测试 CTR、GCM 和 XTS 工作模式，综合分析算法的正确性、吞吐率及侧信道风险。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 李汶峰 | AES、SM4 基线实现及 T-table、AES-NI 优化 |
| 赵孙梦元 | GIFT-128、TWINE-128 及 CTR、GCM、XTS 模式的实现与优化 |
| 孙名璋 | 跨版本正确性测试、性能基准测试、结果分析与文档整理 |

### 4. [SM3 软件实现与 SIMD/GPR 混合优化](./Task%204/)

**实验简介：** 实现 SM3 哈希算法及增量接口，在基线版本上开发 x86-64 AVX2、AVX-512 和 ARM64 NEON 优化路径，并通过运行时分派、多缓冲测试和性能基准验证不同架构实现的正确性与加速效果。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 李汶峰 | SM3 基线实现、AVX2/AVX-512 优化及运行时实现选择 |
| 孙名璋 | ARM64 NEON 路径、多缓冲测试、性能评测与实验文档整理 |

### 5. [基于 TenSEAL CKKS 的密文卷积](./Task%205/)

**实验简介：** 使用 TenSEAL 的 CKKS 全同态加密方案，对单通道 `4×4` 输入和 `3×3` 卷积核执行密文卷积；通过客户端与服务器分离保证私钥不进入服务端，并利用明文参考结果和误差阈值验证计算的正确性。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 安泊仰 | CKKS 参数选择、客户端与服务器流程设计、密文卷积实现 |
| 赵孙梦元 | 明文对照、误差与安全边界测试、结果可视化及报告整理 |

### 6. [CKKS 密文卷积的旋转复杂度与稀疏优化](./Task%206/)

**实验简介：** 分析 TenSEAL 密文卷积中“旋转—累加”过程的复杂度，证明单密文二叉归约模型下的旋转次数下界；利用固定卷积核的稀疏性减少有效乘加项、逻辑槽位和旋转次数，并比较优化前后的计算精度与性能。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 李汶峰 | 旋转复杂度建模、下界证明及 TenSEAL 源码路径分析 |
| 赵孙梦元 | 稀疏卷积优化实现、对照实验、自动化测试与报告整理 |

### 7. [基于 garak 的 DeepSeek 模型安全测评](./Task%207/)

**实验简介：** 使用 garak 对 DeepSeek 模型开展提示注入、DAN 越狱、毒性内容、API Key 泄露、利用型攻击和恶意代码生成六类安全测评，汇总各类测试结果，并分析模型的风险表现与安全边界。

**成员分工：**

| 成员 | 具体分工 |
| --- | --- |
| 安泊仰 | 测试环境与模型接口配置，提示注入、DAN 越狱和毒性内容测评 |
| 孙名璋 | API Key 泄露、利用型攻击和恶意代码生成测评，数据汇总与报告撰写 |
