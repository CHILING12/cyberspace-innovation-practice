# AVX-512 混合实现说明（阶段 4）

## 1. 目标

在 x86-64 上提供与 ref / AVX2 **位级一致** 的 SM3 压缩路径，满足：

- **SIMD 寄存器**负责消息装载、扩展、W′ 生成；
- **通用寄存器（GPR）**负责 64 轮串行压缩；
- **无 AVX512F 的 CPU**：编译保留符号，运行时 CPUID + XCR0 检测后跳过，不崩溃。

## 2. 文件与编译

| 项 | 值 |
|----|-----|
| 源文件 | `src/x86/sm3_avx512.c` |
| 入口 | `sm3_compress_avx512(state, block)` |
| MSVC | `/arch:AVX512`（含 F/BW/DQ/VL 等） |
| GCC/Clang | `-mavx512f -mavx512bw` |
| 宏 | `SM3_HAS_AVX512=1`（CMake 注入） |
| 探测 | `sm3_cpu_has_avx512f()`（`cpuid_x86.c`） |

## 3. 混合数据流

```
 block[64]
     │
     ▼  _mm512_loadu_si512 + vpshufb          ── ZMM
 W[0..15]   (host u32, SM3 大端语义)
     │
     ▼  3-wide SIMD expand (P1 / <<<)         ── XMM lanes + AVX-512 rol
 W[0..67]
     │
     ▼  4 × _mm512_xor_si512                  ── ZMM
 W'[0..63]
     │
     ▼  sm3_compress_rounds_gpr_wp            ── GPR (A..H)
 state[8] ^= ABCDEFGH
```

## 4. 为何扩展是「3 路」而不是 16 路？

扩展递推：

```
W[j] = P1(W[j-16] ⊕ W[j-9] ⊕ (W[j-3]<<<15)) ⊕ (W[j-13]<<<7) ⊕ W[j-6]
```

`W[j]` 依赖 `W[j-3]`，因此：

| 下标 | 依赖的「最近新词」 |
|------|--------------------|
| W[j]   | W[j-3]（已有） |
| W[j+1] | W[j-2]（已有） |
| W[j+2] | W[j-1]（已有） |
| W[j+3] | **W[j]（刚算出）** |

单缓冲下最多 **3 个连续新词** 可向量并行。  
实现中：`j = 16,19,…,64` 共 17 组 ×3，再标量补 `W[67]`。

这是算法依赖决定的，不是实现偷懒；报告中应写明该限制。

## 5. 与 AVX2 路径的差异

| 项目 | AVX2 | AVX-512 |
|------|------|---------|
| 装载 | 2×YMM + pshufb | 1×ZMM + vpshufb |
| 扩展并行 | 逐步 + SIMD P1 | **3-wide** lane 并行 + `rol_epi32` |
| W′ | 8×u32 YMM XOR | **16×u32** ZMM XOR |
| 压缩 | 同一 GPR 轮函数 | 同一 GPR 轮函数 |

## 6. 正确性与验收

1. **有 AVX512 的机器**：`test_vectors` / `test_random` 对 `SM3_IMPL_AVX512` 与 ref 交叉对比。  
2. **无 AVX512 的机器**（当前开发机）：  
   - 目标仍成功编译、链接进 `sm3.lib`；  
   - `sm3_impl_available(AVX512)==0`；  
   - 测试打印 `[SKIP]`；  
   - `AUTO` 选择 AVX2 或 REF。  
3. 压缩轮与 ref **共用** `sm3_compress_rounds_gpr_wp`，消除「SIMD 轮函数写错」类风险。

## 7. 性能预期

- 单缓冲时瓶颈仍在 64 轮 GPR 链；AVX-512 主要优化装载/扩展/W′。  
- 无硬件时无法在本机给出 AVX-512 吞吐数字；有硬件时用 `bench_sm3.exe` 对比 ref/avx2/avx512。  
- 若需大幅吞吐提升，应做 **多缓冲**（多条独立消息），而非只加宽单消息扩展。

## 8. API 使用

```c
if (sm3_impl_available(SM3_IMPL_AVX512)) {
    sm3_set_impl(SM3_IMPL_AVX512);
    sm3_digest(msg, len, out);
}
/* 或一次性： */
sm3_digest_ex(msg, len, out, SM3_IMPL_AVX512);
```
